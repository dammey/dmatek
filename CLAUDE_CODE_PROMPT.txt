Implement the D'Source redesign in the existing Next.js codebase (repo on GitHub, deployed at dsource-web.vercel.app).

Read first: README.md (full spec), tokens.json, then open "DSource v11.1.dc.html" in a browser as the visual and behavioural source of truth. If the README and the file disagree, the file wins. The file is a design reference, not code to ship: rebuild every page with the codebase's own components, routing and styling approach, using tokens.json as CSS variables / theme.

Order of work:
1. Tokens and fonts (Manrope, IBM Plex Mono), global layout, header (Shop, For your business, We'll source it, Pickup repairs, Help, Account; Quote and Cart side by side), footer with adire band.
2. Reusable components: CheckedPanel (takes a category checklist), ConditionBadge, ProductTile, GuaranteeSummary (with manufacturer-warranty footnote), ResponseHours label, QuoteListRow, TrackingStages, Stepper, EmptyState, Icon set (inline SVG), ImageSlot.
3. Home (rotating hero with clip-path wipe, category tiles, SeamEntry swipe with drag/tap/arrow keys and button fallbacks, best sellers, pinned scroll-driven check, place rope kit selector, Office in a Box).
4. Category/Search with working filters, Product (3 versions), Cart/Quote, Checkout, Confirmation/receipt, Tracking, Source request, Repair, Provision, Account, Guarantee, Help, Terms.
5. Motion: page fade-up, scroll reveals, tile-to-product transition, skeleton loading. Respect prefers-reduced-motion everywhere.

Hard rules:
- One store, one catalogue. Remove the For Home / For Business toggle, split navigation, all D'Emporium branding, "Delivered nationwide" and "quotes in 4 working hours".
- Use only the promises listed in README.md with exactly those values. Wherever the 1-hour reply appears, show 8am-8pm daily with it. Do not add other claims, guarantees or free services.
- Terracotta (buy colour) only on primary actions; gold is an accent only; failed-inspection uses the crimson fail colour.
- Real photography only. Leave labelled placeholders where photos are missing; do not use stock photos.
- Leave placeholders marked [ ... ] (prices, order numbers, pay-on-delivery terms, reviews) visible until real content is supplied; never invent values.
- Product data in the file (16 sample items) is illustrative; wire to the real catalogue.
- Mobile first; the design file previews a 390px column and a full-width desktop view, the real site must be fluid.
